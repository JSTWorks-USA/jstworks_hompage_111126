# 연혁(History) 모션 명세서

홈 화면 연혁 장면의 모든 동작을 숫자로 정리한 문서입니다. 이 값을 그대로 쓰면 다른 그림체·색·글꼴로 바꿔도 같은 타이밍과 흐름이 나옵니다.

- 웹 구현: `src/components/home/history-roots.tsx`
- 콘텐츠: `src/content/site.ts` 의 `HISTORY`, `VISION`
- After Effects 구현: `scripts/after-effects/` (생성기 `build-history-roots.mjs`, 빌더 `history-roots.builder.jsx`)
- 렌더 결과: `assets/motion/history-roots.aep`, `assets/motion/history-roots-master.mp4`

이 문서의 값은 2026-11-13 소스 기준입니다. 소스를 고치면 이 문서도 같이 고쳐 주세요.

## 1. 이야기 흐름 (한눈에 보기)

진행도 p는 0(섹션 시작)에서 1(섹션 끝)까지 갑니다. 영상 시간은 p × 20초입니다.

| 진행도 p | 영상 시간 | 화면 |
|---|---|---|
| 0.00 ~ 0.44 | 0 ~ 8.8초 | 카메라가 땅속 깊은 곳에서 출발. 뿌리 끝 7곳에 차례로 불이 켜지고, 빛이 뿌리를 타고 중심으로 흘러가며, 양분 알갱이가 계속 흐름 |
| 0.44 ~ 0.48 | 8.8 ~ 9.6초 | 뿌리 중심(땅 바로 아래)에 빛나는 점이 나타나고 고리가 퍼져 나감 = 매출의 시작 |
| 0.50 ~ 0.84 | 10 ~ 16.8초 | 뿌리 중심에서 줄기를 따라 빛이 위로 차오름. 2027년 계획 2개가 패널에 나옴 |
| 0.84 ~ 0.98 | 16.8 ~ 19.6초 | 빛이 가지 5개로 퍼짐. 나무 윤곽선이 밝아짐. 가지 끝 라벨 5개가 차례로 나타남. 패널은 비전 문구로 바뀜 |
| 1.00 | 20초 | 나무 전체가 빛나고 라벨 5개와 비전이 모두 보이는 마지막 장면 |

카메라는 이 시간 동안 땅속(장면 아래쪽)에서 가지 끝(장면 위쪽)까지 **일정한 속도로** 올라갑니다.

## 2. 시간 축

### 2-1. 웹 (스크롤)

| 항목 | 값 |
|---|---|
| 스크롤 트랙 높이 | `500vh` (실제 스크롤 거리는 400vh) |
| 고정 화면 | 트랙 안에서 `position: sticky`. 데스크톱은 헤더 아래 `top: 4.5rem`, 높이 `100svh - 4.5rem` / 모바일은 `top: 0`, 높이 `100svh` |
| 진행도 원본 | `useScroll({ target: 트랙, offset: ["start start", "end end"] })` 의 `scrollYProgress` (0~1) |
| 장면용 진행도 | 원본에 스프링 적용: `stiffness 140, damping 32, mass 0.6` (스크롤이 멈춰도 부드럽게 따라옴) |
| 패널 단계 판단 | **스프링 전** 원본 진행도로 판단 (스크롤과 즉시 맞도록) |
| 카메라 | 장면용 진행도 0 → 1 에 따라 장면을 `translateY(-65%)` → `0%` 로 선형 이동 |

### 2-2. 영상 (After Effects)

| 항목 | 값 |
|---|---|
| 컴포지션 | 1920 × 1080, 30fps, 20초 (600프레임) |
| 시간 | 영상 시간 = p × 20초. **선형**(스프링 없음). 스크롤로 영상을 재생할 때 스크롤 위치와 프레임이 그대로 맞도록 |
| 카메라 | `Camera` 널 레이어. 장면 단위를 픽셀로 키우고(×1.542857) 위치를 0초 `(497.14, -2005.71)` → 20초 `(497.14, 0)` 로 선형 이동 |

### 2-3. 진행도 구간 표기

이 문서에서 `[a → b]` 는 "진행도 a에서 시작해 b에서 끝나는 선형 변화, 구간 밖에서는 시작값/끝값 유지(clamp)" 를 뜻합니다. 웹의 `useTransform(progress, [a, b], [v0, v1])` 과 같습니다.

## 3. 단계(패널) 데이터

### 3-1. 시작 진행도 공식

- 뿌리 단계(stage `root`) n개: i번째(0부터) = `0.44 / n × i`
- 매출 단계(stage `revenue`): `0.46`
- 줄기 단계(stage `trunk`) m개: j번째 = `0.58 + 0.26 / m × j`
- 비전: `0.84`

현재 콘텐츠는 뿌리 7개, 매출 1개, 줄기 2개, 비전 1개 = 11단계입니다.

## 4. 장면 좌표계

| 항목 | 값 |
|---|---|
| 장면 크기 | 가로 600 × 세로 2000 (SVG viewBox `0 0 600 2000`). 위가 하늘, 아래가 땅속 |
| 한 화면 높이 | 700 단위. 화면 높이에 맞게 확대 (1080px 화면이면 ×1.542857) |
| 가로 배치 | 장면 가로 가운데를 화면 가로 가운데에 맞춤. 배경(하늘·흙)은 좌우로 -600 ~ 1200 까지 넓게 깔아 넓은 화면에서도 빈 곳이 없게 함 |

| 카메라 | 화면 가운데에 오는 장면 y = `(2000 - 700) × (1 - p) + 350`. p=0 이면 1650(땅속 깊은 곳), p=1 이면 350(가지 끝) |

## 5. 레이어 구성 (아래 → 위 순서)

표기: 굵기는 장면 단위(화면에서는 확대 비율만큼 커짐), 불투명도는 0~1.

### 5-1. 하늘 (배경)

- 사각형 x -600 ~ 1200, y 0 ~ 900
- 세로 그라데이션: 위 `night` → 아래 `horizon`
- 움직임 없음

### 5-2. 흙 (배경)

- 사각형 x -600 ~ 1200, y 900 ~ 2000
- 세로 그라데이션: 위 `soil` → 아래 `soil-deep`
- 움직임 없음

### 5-3. 별 70개

- 위치: 결정적 난수로 생성(서버·클라이언트·영상 결과가 같음)
  - 난수: Park–Miller, 씨앗 7. `s = s × 16807 mod 2147483647`, 값 = `(s - 1) / 2147483646`
  - 별 하나마다 난수 4개를 순서대로 사용: x = r×600, y = 20 + r×640, 반지름 = 0.8 + r×1.6, 지연 = r×3초
- 색: `night-foreground`(흰색)
- 반짝임: 불투명도 0.25 ↔ 1, 한 번 3.2초, 왕복(alternate), 무한 반복, 이징 `ease-in-out` = `cubic-bezier(0.77, 0, 0.175, 1)`, 별마다 위 지연만큼 늦게 시작

### 5-4. 흙 알갱이 60개

- 별 70개를 만든 **뒤 같은 난수로 이어서** 생성: x = r×600, y = 940 + r×1040, 반지름 = 1 + r×2.5
- 색 `mint-line`, 불투명도 0.06
- 움직임 없음

## 9. After Effects 구현 세부

| 항목 | 값 |
|---|---|
| 장면 단위 → 픽셀 | `Camera` 널(앵커 0,0, 크기 154.29%)의 자식 레이어로 장면 요소를 두고, 장면 좌표를 그대로 사용 |
| 선이 그려지는 효과 | 모양 레이어의 Trim Paths 끝(End) 0 → 100 |
| 양분 알갱이 | 위치 표현식 `path.pointOnPath(((time - 지연) mod 2.4) / 2.4)` 로 같은 뿌리의 바탕 선을 따라감 |
| 별 반짝임 | 그룹 불투명도 표현식 (3.2초 왕복, 0.25 ↔ 1, ease-in-out 근사) |
| 매출 고리 | 그룹 크기·불투명도 표현식 (2.4초 반복, ease-out 근사 `1 - (1 - t)^3`) |
| 라벨 | 장면 좌표에 둔 널(크기 = 100 ÷ 1.5429 %)의 자식으로 알약·글자를 두어 픽셀 크기 유지 |
| 패널 | 화면 고정 레이어. 크기·위치는 단계마다 HOLD 키프레임, 내용은 단계별 널 + 불투명도·위치 키프레임 |
| 배경 | 단색 레이어 + Gradient Ramp 효과 |
| 렌더 | `aerender` + 출력 모듈 "H.264 40Mbps" (한국어 AE에서는 "H.264 - 렌더링 일치 설정 - 40Mbps") |

다시 만들기:

```bash
# 1) 소스에서 After Effects 스크립트 생성
node scripts/after-effects/build-history-roots.mjs

# 2) 열려 있는 After Effects 에서 실행 (프로젝트 저장, 렌더 대기열 등록까지)
osascript -e 'with timeout of 7200 seconds' \
  -e 'tell application "Adobe After Effects 2027" to DoScript "$.evalFile(new File(\"<저장소>/assets/motion/history-roots.jsx\"))"' \
  -e 'end timeout'

# 3) 렌더
"/Applications/Adobe After Effects 2027/aerender" -project <저장소>/assets/motion/history-roots.aep \
  -comp "History Roots" -OMtemplate "H.264 - 렌더링 일치 설정 - 40Mbps" \
  -output <저장소>/assets/motion/history-roots-master.mp4
```

After Effects 설정에서 "스크립트가 파일을 쓰고 네트워크에 액세스하도록 허용"이 켜져 있어야 합니다.

## 10. 다른 디자인으로 바꿀 때 체크리스트

1. **콘텐츠가 바뀌었나?** 단계 수가 바뀌면 §3-1 공식으로 시작점을 다시 계산하고, 뿌리 끝 위치(§5-7 규칙)도 다시 계산합니다. 생성기를 쓰면 자동으로 됩니다.
2. **그림을 바꾸나?** 나무·뿌리·줄기·가지 경로를 새 그림으로 바꾸되, 다음은 유지합니다.
   - 뿌리 끝은 각 단계가 활성일 때 화면 가운데 근처에 보일 것
   - 모든 뿌리가 한 점(매출 지점)으로 모일 것
   - 줄기 빛은 매출 지점에서 시작해 가지 갈림점에서 끝날 것
   - 가지 끝 라벨 5개가 마지막 장면 한 화면 안에 다 보일 것 (좁은 화면 포함)
3. **색을 바꾸나?** §7-1 토큰만 바꾸고, 빛 색이 가장 밝은지와 패널 글자 대비를 확인합니다.
4. **타이밍을 바꾸나?** §1 구간 경계(0.44, 0.46, 0.50, 0.84)를 바꾸면 §3-1, §5-10~13 구간도 같이 옮깁니다.
5. **확인**: 진행도 0, 0.2, 0.44, 0.48, 0.6, 0.84, 0.95, 1.0 의 장면을 캡처해 §1 표와 같은 일이 일어나는지 봅니다. 움직임 줄이기 설정을 켜고 정적 목록이 나오는지도 확인합니다.
